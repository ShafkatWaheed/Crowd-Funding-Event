Announcement Banner on Top

Collapsible announcement banner at the top shows latest post. DM indicator below it. Tickets list underneath. Tapping banner → full announcement channel. Tapping DM → opens chat.

Pros

  • Announcements always visible
  • Tickets remain primary focus
  • Minimal layout change

Cons

  • Banner can push tickets down on small screens
  • Multiple events = stacked banners

Segmented Toggle

Tab renamed to "Activity" or keeps "Tickets". Segmented control at top switches between Tickets view and Messages view. Badge on Messages segment shows unread count. Messages view grouped by event.

Pros

  • Clean separation — no clutter
  • Full screen for each view
  • Badge draws attention to messages

Cons

  • Messages hidden behind one tap
  • User might miss announcements if they stay on Tickets

Unified Event Cards

Each event is a card showing: ticket(s), announcements, and DM — all in one place. Everything the customer has for that event, grouped together. Tab could be renamed "My Events" or "Activity".

Pros

  • Everything in one glance per event
  • Natural grouping — ticket + comms together
  • Announcements always visible (no toggle)

Cons

  • Cards get tall with multiple tickets
  • More complex UI to build
