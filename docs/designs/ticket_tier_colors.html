Ticket Tier Color Schemes

Three approaches — Scheme 1 is keyword-aware, 2 is price-ranked, 3 is index-cycled

Scheme 1
Name Keyword Detection
Color is derived from the tier name. "Free" → green, "General" → blue, "Premium" → purple, "VIP / Gold / Platinum" → amber, "Early Bird" → teal. Fallback to blue for unrecognised names.

Scheme 2
Price Position
Tiers are sorted by price and colors assigned by rank: Free → green, cheapest paid → blue, middle → purple, most expensive → amber. Works even with generic names like "Tier A / Tier B".
